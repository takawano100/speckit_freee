# Quickstart: 動かし方と検証

## 前提
- node 20+（検証スクリプト）。ブラウザは Chrome / Edge
- ローカルサーバー：`open-local.cmd` または `python -m http.server 4173`

## 1. 検証スクリプト（T01〜T30 を data/*.json で確かめる）

```powershell
node check_saburoku.js
```

期待：`OK: T01, T02, ...` と確認したケースの一覧。1つでも違えば `NG: T07 ...` と出て終了コード 1。
検証は `saburoku_calc.js` の純関数だけを呼ぶ（DOM を使わない）。
